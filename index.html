호기별 정비 이행 현황

점검 이행 관리 탭과 같은 기준입니다. 칸 = 해당 연도 정비 등급과 점검항목 수행 수 / 해당 항목 수. 14년부터 올해까지만 표시되며 해가 바뀌면 한 해씩 늘어납니다. 칸을 누르면 해당 체크리스트로 이동합니다.

초안 확인 필요 사항

    호기별 정비 이력·계획

    칸 위에 마우스를 올리면 메모가, 칸을 누르면 등급·월·메모를 직접 고치는 창이 열립니다(빈 칸도 가능). ◆ Fast-gen · ! 고장/비계획 · ✦ 부품 교체 · * 점선(점) = Claude 권고 추정: 마지막 기록 +3년, 마지막 A급 이후 3년 C · 6년 B · 9년 C · 12년 이상 A 규칙 적용. 표는 올해 + 7년까지 자동으로 늘어나며(해가 바뀌면 한 칸씩 이동), 그 밖의 연도는 아래에서 직접 추가할 수 있습니다.

    전 호기 엑셀 업로드

    저장됨
    엑셀 한 파일로 모든 호기를 한 번에 올립니다. 올린 내용은 먼저 화면에만 반영되며, [저장하기]를 눌러야 이 브라우저에 저장됩니다(저장 전에는 [변경 취소]로 되돌릴 수 있습니다). 읽는 형태: ① 기존 "발전기 점검 이력"(호기별 9줄 블록: 날짜·시행처·공사명·절연저항·P.I·ΔI·tanδ·P.D·특이사항, 회차가 가로 열) ② 한 줄에 한 번의 진단을 적은 표(열: 호기·날짜·시행처·공사명·절연저항·성극지수·교류전류·유전정접·부분방전·특이사항). 날짜가 기간("2011-04-29~05-22")이면 시작일로 저장하며, 같은 호기·날짜·공사명은 갱신, 없으면 추가합니다.

    호기 선택

    등급별 점검항목

    각 등급에서 수행(O)하는 항목 수. 상위 등급은 하위 등급 항목을 대부분 포함합니다.
    칸에 O = 수행, 비우면 미수행, 그 밖의 글자(예: 인출X)는 조건 표시입니다. 입력하면 바로 이 브라우저에 저장됩니다. 다른 사람에게도 보이게 하려면 화면 위쪽 [☁ 모두에게 반영]을 누르세요.

    점검 이행 관리 (복합 3~9호기)

    정비 이력·계획 탭에 있는 연도별 등급(C/B/A)에 해당하는 점검항목을 실제로 수행했는지 체크합니다. 표의 칸을 누르면 아래에 체크리스트가 열립니다. 칸 안의 숫자는 수행 항목 수 / 해당 항목 수입니다. 등급별 점검항목 탭에서 항목을 추가·삭제·수정하면 이 탭에 자동 반영되고, 항목 이름을 고쳐도 기존 체크는 유지됩니다.
    전체 수행일부 수행미수행(!) 있음미입력점선 = 계획(아직 시행 전)

    등급

    수치는 A상/B상/C상 순서로 슬래시(/)로 구분해 적습니다. 예: 5,100/5,160/5,230

    GitHub 연결 설정

    [모두에게 반영]을 누르면 저장소의 data.json 파일을 갱신(커밋)합니다. 토큰은 이 브라우저에만 보관되며, 공개 페이지 코드에는 들어 있지 않습니다. 토큰은 이 저장소 하나에만 Contents 읽기·쓰기 권한을 준 Fine-grained token을 권장합니다.
